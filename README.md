# Atelier Ina

Website for Ina Lubbers — kleding op maat, naailessen and workshops in Aalten.

Content lives in `content/` as structured YAML so it can later move to Sanity without rewriting the UI.

## Setup

Requires Node 22 (see `.nvmrc`).

```bash
npm install
npm run dev
```

```bash
npm run generate
```
